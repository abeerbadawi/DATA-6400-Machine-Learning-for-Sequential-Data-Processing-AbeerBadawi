# Paracheck

## Evaluating Paraphrased Answer Consistency of Large Language Models in Multiple-Choice Commonsense Questions

**Team:** Aishat Disu, Aishwarya Ramesh, Chathushi Thalpage, Chengcheng (Jessie) Jiang, Taylor Uylett-Kerrigan

This project tests whether LLM answers remain consistent when multiple-choice commonsense questions are rewritten using meaning-preserving paraphrases of different strengths.
