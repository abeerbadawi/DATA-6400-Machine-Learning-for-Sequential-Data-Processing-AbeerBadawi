# MentalX

## From Generalization to Clinical Utility: A Strategic Alignment Pipeline for Qwen 3-4B in Mental-Health Dialogue

**Team:** Ridwan Adeniyi, Hao Han, Zhengyang Li, Rui Wang, Bin Liu

This project studies prompt engineering and parameter-efficient alignment of a lightweight language model for mental-health dialogue, together with structured evaluation of response quality.
