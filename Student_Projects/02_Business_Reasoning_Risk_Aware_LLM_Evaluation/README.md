# Business Reasoning

## From Accuracy to Reliability: Risk-Aware Evaluation of Large Language Models for Decision-Support Under Sampling Variability

**Team:** Barath Sanjeevan, Sanika Rozario, Aadesh Vijayaraghavan

This project examines reliability, stability, hallucination risk, and reasoning selection when LLM outputs vary across repeated samples.
