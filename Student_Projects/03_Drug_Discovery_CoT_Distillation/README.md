# Drug Discovery

## Chain-of-Thought Distillation for Drug-Drug Interaction Prediction: Transferring Pharmacological Reasoning from Large to Small Language Models

**Team:** Yumna Khan, Rameen Jafri, Vian Lelo, Mohammadreza Riyazat, Yuyao Wu

This project investigates knowledge distillation of pharmacological chain-of-thought reasoning from a large teacher model to a smaller language model for drug-drug interaction prediction.
