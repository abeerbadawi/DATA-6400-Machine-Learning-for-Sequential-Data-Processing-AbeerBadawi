# Humanity's Last Proctors

## V-BReE: A Variance-thresholded Blinded Refinement Ensemble for Multi-Agent LLM Reasoning

**Team:** Milad Ebrahimi Abyazandi, Sherwin Darryl D’Souza, Jeremy Greenwood, Jason Ives

This project explores a blinded iterative multi-agent ensemble intended to reduce context-induced bias, conformity, and sycophancy in collaborative LLM reasoning.
