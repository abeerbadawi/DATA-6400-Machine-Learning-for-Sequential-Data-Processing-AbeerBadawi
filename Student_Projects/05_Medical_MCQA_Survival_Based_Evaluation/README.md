# Medical MCQA

## Beyond Accuracy: A Survival-Based Evaluation Framework for Elimination Reasoning in Medical Multiple-Choice Question Answering

**Team:** Adam Sadowski, Shubham Mehla, Monil Patel

This project evaluates medical multiple-choice reasoning as a sequential elimination process and develops metrics that track whether the correct answer survives across reasoning rounds.
