# Rainfall

## Multi-basin Rainfall–Runoff Modelling with LLM-based Zero-Shot Basin Generalization

**Team:** Mason Marchildon, Takeshi Yagiuchi

This project investigates whether text-based representations of watershed characteristics can support transfer and zero-shot generalization in multi-basin rainfall–runoff modeling.
